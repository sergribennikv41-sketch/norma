# Сторонние материалы

## Russian Recipes Parser / vkuso.ru

Пилот из 5000 рецептов импортирован из RuRecipes-93k (https://huggingface.co/datasets/epishchik/RuRecipes-93k), источник russianfood.com.

Датасет распространяется по лицензии CC BY-NC 4.0 (только некоммерческое использование). Фото russianfood.com требуют отдельного разрешения для публикации. Пилот используется локально.

Для каждого рецепта поле `source` содержит ссылку на исходную страницу. Фото скачаны локально для пилота.

## Шрифты

В приложении используются шрифты Golos Text и Unbounded из Google Fonts. Они распространяются по лицензии SIL Open Font License 1.1. Тексты лицензий лежат в `assets/fonts/OFL-GolosText.txt` и `assets/fonts/OFL-Unbounded.txt`.

## Остальной контент

Сгенерированных рецептов в базе нет: только импортированный пилот. Иконка и оформление приложения — оригинальные материалы проекта.

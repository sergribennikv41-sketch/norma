# Норма

Локальное приложение для Windows и Android на Flutter: расчёт КБЖУ и подбор рациона на неделю с учётом цели, активности, аллергенов и времени готовки.

## Возможности

- Расчёт BMR/TDEE по Миффлину-Сент-Джору и целевых КБЖУ.
- Меню на 7 дней с автоматическим масштабом порций под норму.
- Календарные недели Пн–Вс: текущая неделя, история и переход по неделям.
- Генератор учитывает тип приёма пищи: завтрак, обед, ужин или перекус.
- Фильтры: аллергены и максимальное время готовки.
- Ручной выбор альтернатив блюда, лайки и блокировки.
- Каталог рецептов: поиск по названию блюда или продукта, отдельные секции «Блюда» и «Продукты», подсветка совпадений.
- Добавление блюда из каталога в выбранный день и приём пищи.
- Импорт рецептов из JSON: меню ⋮ → «Импортировать рецепты».
- В карточке рецепта: кнопка «Видео в Pinterest» с поиском по названию блюда.
- Локальные фото блюд для 2000 рецептов; при отсутствии фото — аккуратная заглушка с названием блюда.
- Ручная правка порции в карточке блюда.
- Список покупок: агрегация, live-цены по выбранному городу и магазину, чекбоксы и копирование в буфер.
- Цены не сохраняются на диск: ищутся при раскрытии списка покупок и кэшируются только в памяти до закрытия приложения.
- Город и основная сеть выбираются в профиле; сейчас подключён Магнит, остальные сети — после добавления адаптеров.
- Локальное сохранение профиля и снимков планов по неделям.
- Полный редизайн: сайдбар, экран рациона с днём и карточками блюд, каталог, покупки и профиль.
- Светлая «Тёплая» и тёмная «Графит» темы с переключением и сохранением выбора.
- Своя иконка, заголовок окна «Норма» и запоминание размера/позиции.
- SQLite-база: 75 ингредиентов и 2000 рецептов из RuRecipes-93k.
- Seed-файл `assets/data/seed.json` — канонический источник, при первом запуске импортируется в SQLite.
- Все 2000 рецептов с локальными фото из russianfood.com.
- Импорт/экспорт seed-данных через JSON-структуру; расширение базы — `tool/expand_rurecipes.py`.

## Стек

- Flutter 3.47.9, Dart 3.13.7, Material 3.
- SQLite: `sqflite_common_ffi` на Windows, `sqflite` на мобильных.
- `shared_preferences` для профиля, недель и выбранного города/магазина.
- Python 3 + Playwright для live-поиска цен через каталог магазина.
- Шрифты Golos Text и Unbounded (SIL OFL) в `assets/fonts/`.

## Сборка

Portable-версия:

```powershell
powershell -ExecutionPolicy Bypass -File tool\build_windows.ps1
```

Результат: `dist\norma-<версия>-windows-x64-portable.zip`.

Установщик:

```powershell
winget install --id JRSoftware.InnoSetup -e
powershell -ExecutionPolicy Bypass -File tool\build_installer.ps1
```

Результат: `dist\norma-<версия>-windows-x64-setup.exe`.

## Android

```powershell
flutter build apk --release
```

APK: `build\app\outputs\flutter-apk\app-release.apk`.

Live-цены сейчас работают в Windows-версии через локальный Python-обработчик. В Android APK они появятся после подключения мобильного источника цен.

## Подпись установщика

Нужен сертификат code signing (OV/EV) в формате PFX:

```powershell
powershell -ExecutionPolicy Bypass -File tool\sign_installer.ps1 -PfxPath C:\path\cert.pfx
```

Пароль можно передать через переменную `NORMA_PFX_PASSWORD`. Без сертификата установщик не подписан, SmartScreen предупреждает.

## Данные

- Seed: `assets/data/seed.json` (ассет приложения, версия 25).
- Пилот: 2000 рецептов из RuRecipes-93k, отобранных по маппингу ингредиентов.
- Фото: локальные файлы, скачанные с russianfood.com для этих рецептов.
- Импорт/расширение базы: `tool/expand_rurecipes.py`; текущие 2000 рецептов собраны из RuRecipes-93k.
- Рецепты и ингредиенты: SQLite `%APPDATA%\ru.norma\norma\norma.db`.
- Профиль, город, магазин и снимки рационов по неделям: `shared_preferences`.
- Live-цены не сохраняются: кэш живёт только в памяти до закрытия приложения.
- Сервер приложения не используется; для поиска цен нужен интернет и доступ к каталогу магазина.
- Сейчас подключён Магнит; остальные сети требуют отдельных адаптеров `tool/price_lookup.py`.
- Внешние источники рецептов и лицензии: `RECIPE_SOURCES.md`.

## Формат импорта

Файл seed: `assets/data/seed.json`. Версия seed хранится в базе; при её росте данные обновляются через merge, поэтому пользовательские импорты сохраняются. Расширить набор: `dart run tool/generate_recipes.dart`.

Пример для ручного импорта: `examples/import_example.json` (меню ⋮ → «Импортировать рецепты»).

`SeedBundle.fromJson` принимает объект с ингредиентами, ценами и рецептами:

```json
{
  "version": 1,
  "ingredients": [
    {
      "id": "oats",
      "name": "Овсяные хлопья",
      "category": "Крупы и макароны",
      "per100g": {"calories": 352, "protein": 12.3, "fat": 6.1, "carbs": 61.8},
      "allergens": [],
      "pricePerKg": 120
    }
  ],
  "recipes": [
    {
      "id": "oatmeal",
      "title": "Овсянка",
      "mealTypes": ["breakfast"],
      "servings": 1,
      "minutes": 10,
      "ingredients": [{"ingredientId": "oats", "grams": 60}],
      "steps": ["Сварите хлопья."],
      "image": "C:/photos/oatmeal.jpg"
    }
  ]
}
```

`image` необязателен: локальный путь, assets-путь или HTTP(S)-ссылка. При ошибке загрузки показывается заглушка по типу приёма пищи. `source` хранит ссылку на страницу и сведения об источнике; она отображается в карточке рецепта.
